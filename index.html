LongContextVLA:Scaling Robot Memory to
Hundreds of Images

Anonymous authors

Abstract

Vision-language-action (VLA) models typically condition on only the current observation or a small set of past keyframes. This limits their ability to solve long-horizon tasks that require persistent visual memory. We develop a VLA that conditions on more than 200 images of visual history while maintaining real-time inference speed. Our approach builds on Qwen3.5-4B, a multimodal model with a 262K-token context window, which we fine-tune for robotic control. We find that long visual context alone is insufficient for robust generalization on memory-intensive tasks, so we train the VLA to reason over and narrate events in its visual history, using parallel decoding to avoid the latency cost of autoregressive reasoning. By caching past visual tokens and processing only newly arriving images, our streaming implementation achieves per-step latency close to that of a single-image VLA. We evaluate our approach on a long-horizon shell game and object retrieval task, achieving average 83% success in unseen scenarios, as well as competitive performance on the RoboMME benchmark. Finally, we demonstrate memory-based prompting, where the robot observes a human demonstration and reproduces the demonstrated behavior, and can generalize to new scenarios. Together, our results show that scalable visual memory, learned reasoning, and streaming inference enable real-time, long-horizon robot control.

Our Approach

Unlike approaches that compress visual history into selected keyframes or textual summaries, LongContextVLA retains the full sequence of visual observations sampled at 2 Hz. As shown below, the model builds on Qwen3.5-4B and conditions on this visual history, current wrist images, the task instruction, and the robot’s joint states. It produces three outputs: memory narration, subtask prediction, and action generation. Memory narration provides supervision for reasoning about task-relevant events in the history. The model then predicts the current subtask and generates action tokens, which the OAT decoder converts into a continuous action sequence.

This design introduces two potential sources of latency. First, generating a narration word by word is too slow for real-time control. To combat this, we append a block of reserved tokens and decode the narration in parallel in a single forward pass. The model uses the representations at these positions to predict the subtask and actions without autoregressively generating and feeding back the narration.

Second, repeatedly processing the entire visual history would become increasingly expensive as an episode progresses. We therefore cache past visual features and model state, including attention keys and values and the backbone’s recurrent state (for the Gated DeltaNet layers of Qwen3.5). At each decision, the model processes only newly received observations alongside the current decision inputs, reusing computation from earlier images. This keeps inference latency close to that of a short-context VLA over a substantial range of history lengths, although latency still grows as new tokens attend to the expanding history.

RoboMME Results

On RoboMME, LongContextVLA achieves 84.9% average success across 16 tasks, evaluated on 50 episodes per task (800 episodes total). This is 40.4 percentage points above the strongest compared non-oracle baseline in the paper.

Streaming inference keeps long histories practical

Caching avoids recomputing the full history at each decision. In the latency scaling experiment, cached inference stays below one second at approximately 258K historical visual tokens on both H100 and B200 GPUs.
